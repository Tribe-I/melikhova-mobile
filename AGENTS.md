# AGENTS.md — melikhova-mobile

## Назначение

Мобильное приложение «Чек-лист диджитал продакта» на React Native с Expo (TypeScript). Это перенос лендинга https://tribe-i.ru/melikhova/landing/ (репозиторий `Tribe-I/melikhova-repo`). Обещания приложения перечислены в `README.md`, их нельзя нарушать.

## Правила

- Только React Native и Expo. Без WebView, без показа веб-страницы внутри приложения, без Flutter, Capacitor и нативного кода.
- Базовые компоненты React Native: View, Text, Image, ScrollView, Pressable. Допущены две библиотеки: `@react-native-async-storage/async-storage` (хранение оценок) и `react-native-svg` (кольцо и радар). Новые библиотеки только с согласия владельца, сначала объяснить зачем. Ставить через `npx expo install`.
- Два экрана без библиотек навигации: «Главная» и «О приложении».
- Хеш коммита берётся из `EXPO_PUBLIC_COMMIT`, без неё показывается `dev`. Руками хеш в код не писать.
- Новые пункты в `src/data/checklist.json` добавлять только в конец блока: оценки сохраняются по номеру пункта в блоке.
- Формулу не менять без согласования: «Да» 1, «Частично» 0,5, «Нет» 0 (`src/lib/score.ts`).

## Команды

```bash
npm install
npx expo start      # запуск, QR-код для Expo Go
npx tsc --noEmit    # проверка типов
npx expo lint       # линтер
```

Перед сдачей любой задачи запустить проверку типов и линтер.

## Как вносить изменения

Изменения только через ветку и pull request, в `main` напрямую не коммитим. Сборки EAS и workflow в `.github/` настраивает владелец.

## Секреты

Паролей, ключей, токенов, файлов `.env`, адресов внутренних сервисов и персональных данных в репозитории нет и быть не должно. Токены хранятся только в GitHub Secrets, в коде остаются лишь их имена.
